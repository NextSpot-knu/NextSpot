## 8. 새로 더한 것 — 웹 행동 기록 (심사위원이 실제로 썼는지 확인용)

사용자 결정(11-12): 모든 방문 기록 + 로그인하면 계정 연결 · IP 원본 1년 보관 · 입력 내용은 검색어 · 음성 비서 문장만.

- **표** `public.action_logs`(`supabase/migrations/20261112090000_action_logs.sql`)
  - 브라우저는 9칼럼만 INSERT 한다(`occurred_at` `device_id` `session_id` `seq` `event` `page` `host` `locale` `props`). 이벤트 16종은 CHECK 로 묶고 웹 `ACTION_LOG_EVENTS` 와 테스트로 대조한다.
  - 계정(`user_id`) · 게스트 여부 · 역할 · IP(`ip` + 원문 `ip_chain`) · 브라우저 정보 · 받은 시각은 DB 트리거가 요청에서 찍는다. 브라우저가 보낸 값은 믿지 않는다.
  - 고치기 · 1년 안 지우기 · TRUNCATE 는 트리거가 막는다(service_role 도 UPDATE·DELETE 권한 없음). 1년 지난 행은 pg_cron `nextspot-action-logs-retention` 이 지운다. 같은 `(session_id, seq)` 는 한 번만 들어간다.
  - 남용 상한: 브라우저 요청 하나에 50줄, 같은 IP 는 1분에 600줄까지(넘는 줄은 버린다). 쌓인 스팸은 표 소유자가 가드를 잠시 끄고 지운다(절차는 마이그레이션 파일 끝).
  - 읽기는 developer 만: RPC `action_log_devices` · `action_log_rows`(그 밖 역할은 42501). 관리자도 못 본다 — 심사위원이 관리자 계정을 쓴다.
- **웹**(`lib/actionLog.ts` · `components/shell/ActionLogger.tsx`)
  - 남기는 것: 접속 시작 · 화면 이동 · 버튼·링크 누름(이름) · 입력 칸 종류와 글자 수 · 제출 · Esc/Enter · 쓸어넘김 · 스크롤 깊이 · 지도 확대 단계와 누른 핀의 장소(좌표 없음) · 쿼리만 바뀐 이동 · 화면 보임/숨김 · 화면이 열려 있는 동안 30초마다 신호(10분 넘게 조작이 없으면 5분마다) · 우리 API·Supabase 응답 결과 · 오류 · 로그인 상태.
  - 글 내용은 검색어와 음성 비서 문장만(이메일·전화번호 모양은 가린다). 관광객 검색 · 음성 비서 · 음성 검색 · 관제 장소·인프라·쿠폰 검색에 직접 연결했다. 관제 문의 검색어는 문의 내용이 섞일 수 있어 남기지 않는다.
  - 남기지 않는 것: 비밀번호 · 이메일 · 문의 본문 · 프로필 칸 값 · 음성 녹음 · 위치 좌표(주소의 좌표 값도 `[geo]` 로 바꾼다).
  - 운영 주소(`nextspot-nu.vercel.app` + `NEXT_PUBLIC_ACTION_LOG_HOSTS`)에서만, 자동화(e2e)는 뺀다. 추적 거부(DNT) 설정과 관계없이 남긴다(우리 서비스 자체의 운영 기록 — 안내에 적었다).
  - 전송은 3초 묶음 · 탭마다 저장소 대기열 · 재시도. 중복(409)은 이미 저장된 것으로 보고, 페이지를 떠날 때 보낸 줄도 확인될 때까지 대기열에 남긴다(다음 방문이 다시 보낸다). 일시 오류로 멈추면 3분 뒤부터 다시 시도한다. 테이블이 아직 없으면 그 페이지에서 멈추고 대기열을 지킨다(마이그레이션 적용 뒤 보낸다).
