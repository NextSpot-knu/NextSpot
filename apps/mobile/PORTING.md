# 웹 → 앱 이식 원본 추적

앱이 웹 코드를 **다시 쓴** 파일의 원본을 적는다. 웹 원본이 기준 커밋 뒤에 바뀌면 앱도 반영할지 본다
(`git log <기준 커밋>.. -- <웹 원본>`). 그대로 import 하는 순수 모듈은 여기 적지 않는다 — `npm run check:shared` 가 지킨다.
